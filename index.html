Tentang

Sejak 2019 saya memonitor pickup dan reverse logistics untuk mitra marketplace di JNE: Shopee, TikTok, Tokopedia, Lazada, dan Blibli. Dari situ saya belajar bahwa laporan yang baik bukan yang paling lengkap, tetapi yang membuat cabang tahu harus berbuat apa hari ini.

Saya membangun dashboard performa kurir, mengotomasi analisis keterlambatan pickup, dan membuat web tool internal. Semuanya berangkat dari masalah nyata di lapangan, dengan SLA di atas 95% untuk pelanggan B2B.

Proyek

Dashboard resi gagal dan performa kurir

Power BI

Masalah
Customer meminta review resi gagal dan performa pickup tiap dua minggu, dan rekap manual memakan waktu.
Solusi
Dashboard untuk meeting dua mingguan dengan customer: ringkasan resi gagal, coding status, alert level per regional, status unsuccess berdasarkan waktu entry online, performa kurir per attempt, dan kategori follow up.
Hasil
Dipakai sebagai bahan evaluasi resi gagal dan performa pickup dalam meeting rutin dengan customer.

Otomasi analisis late pickup

Python, Pandas

Masalah
Analisis keterlambatan pickup per cabang dikerjakan manual.
Solusi
Script yang menghitung keterlambatan dan performa kurir per cabang.
Hasil
Analisis keterlambatan dan performa kurir per cabang berjalan otomatis, tanpa rekap manual.

Web tool validasi resi reverse pickup

JavaScript, Python

Masalah
Data harian Shopee tidak memuat detail alamat yang lengkap.
Solusi
Web tool untuk mengecek banyak resi sekaligus dari input teks atau file, memvalidasi per kategori (Complain, Direct Data, Validasi Report), menyimpan hasilnya di server, dan mengekspor ke Excel, CSV, atau JSON.
Hasil
Ribuan resi dapat divalidasi dan diekspor dalam satu laporan, dengan detail alamat yang sudah dilengkapi.

Tool analitik foto bukti pickup

Web tool

Masalah
Kualitas pickup sulit dinilai tanpa melihat foto bukti satu per satu.
Solusi
Tool web yang menampilkan foto bukti pickup dari daftar tautan atau file, dengan pencarian, pemilihan foto, dan unduhan hasil pilihan ke Excel, untuk memantau kualitas pickup dan performa kurir.
Hasil
Pemantauan kualitas pickup dan performa kurir dilakukan langsung dari foto bukti.

Rekap CBC Hub untuk monitoring case

Node.js, Express

Masalah
Data case tiap PIC tersebar di file Excel masing-masing, sehingga monitoring case by case sulit dan lambat.
Solusi
Aplikasi web internal yang menggabungkan data case seluruh PIC dari file Excel ke satu dashboard: total case, open, claim, closed, performa per PIC, kategori interaksi, dan halaman laporan. Tim mengaksesnya lewat jaringan lokal.
Hasil
Data case seluruh PIC terkumpul di satu tempat dan bisa difilter per PIC.

Trace-W, sistem monitoring kendala warehouse

CodeIgniter 4, MySQL

Skripsi
Implementasi Sistem Trace-W Berbasis Web untuk Monitoring Kendala Warehouse Logistik di PT Bangun Desa Teknologi.
Peran
Merancang dan membangun Trace-W sendiri sampai versi final.
Masalah
Pelaporan dan penanganan kendala warehouse berjalan lewat media komunikasi, sehingga tiket tidak terdokumentasi secara terpusat. Status penanganan sulit dipantau dan riwayat penyelesaian sulit dicari.
Solusi
Trace-W (Tracking and Response Agent Case for Warehouse), aplikasi web untuk melaporkan, memantau, dan menangani kendala warehouse. Dikembangkan dengan metode Waterfall dan diuji dengan Black Box Testing.
Fitur
Upload data tiket, status Open, Progress, Pending, dan Close, catatan dan riwayat penanganan, pencarian dan filter, dashboard, laporan ke Excel dan PDF, notifikasi WhatsApp saat tiket ditutup, serta hak akses admin dan user.
Hasil
Seluruh fungsi utama lulus pengujian Black Box. Kendala kini terdokumentasi dalam satu sistem, sehingga status dan riwayat penanganan mudah diakses.
